# PlayBox — Offline Arcade PWA

Flat-root offline-first Progressive Web App featuring 4 single-player and local 2-player games with IndexedDB stats persistence, JSON backup/restore, and Web Audio synthesized sound effects.

## Run Locally
Serve the folder over HTTP/HTTPS so the Service Worker can register:
```bash
npx serve .
```
Or upload all 12 files directly to the root of a GitHub repository and enable GitHub Pages.
