# PlayBox — Offline Arcade PWA

Offline-first Progressive Web App featuring 4 single-player and local 2-player games with IndexedDB stats persistence, JSON backup/restore, and Web Audio synthesized sound effects.

## Run Locally
Serve the folder over HTTP/HTTPS so the Service Worker can register:
```bash
npx serve .
```
Or upload the contents of `playbox/` directly to a GitHub repository and enable GitHub Pages.
